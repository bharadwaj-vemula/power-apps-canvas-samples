## 🚀 Quick Start

```bash
git clone https://github.com/bharadwaj-vemula/power-apps-canvas-samples.git
pac canvas pack --sources ./samples/01-starter-app --msapp ./app.msapp
```

> 🔒 All samples are sanitized: no client data, tenant IDs, or secrets.
